Billing mails: copy review v2

v2 after Max's picks. Part 1 shows the chosen variant of each of the seven mails, revised. Part 2 has three variants for the one new piece: the help line that invites a reply. Every chosen mail renders with the recommended help line. Copy only, nothing built yet.

Every variant passed the humanizer check (no em dashes, no AI vocabulary). Voice: tone-of-voice.md. No amounts anywhere; prices live in Stripe.

How to choose

Reply with one letter for the help line, for example help-line: A. Edits to a chosen mail: name the id and the line.

Decisions (Max, 2026-10-09)

  1. Picks: trial-0 B, trial-7 C, trial-12 A, trial-ended A, trial-21 C, payment-failed A, canceled A.
  2. Billing mails are replyable. Every help line says "reply to this email"; replies go to support@plus-one.io (reply-to). The help line has 3 variants below.
  3. Days 7, 12, 14 and 21 count from the trial end date, so a trial override moves them along.
  4. Day 21 is sent.
  5. payment-failed and canceled go out every time, keyed per Stripe event or invoice, not once per company.
  6. A short trial override skips any mail whose day has already passed. No catch-up.

Sender

  • Shown as From: PlusOne <support@plus-one.io>, Reply-to: support@plus-one.io. A visible "noreply@" next to "reply to this email" reads as a contradiction, so sending from support@ is the recommendation. If it stays noreply@, the reply-to still routes replies to support@ and the copy holds.
  • The help line starts with "Reply", with no filler word in front of it, per the banned filler list in docs/copy-prompt.md.
